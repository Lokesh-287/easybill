# Keyboard-First POS Ergonomics & Fintech UI

## Overview
Design principles and interface standards designed for high-stress retail checkouts, minimizing mouse dependence, maximizing scan-to-print velocity, and adhering to modern fintech aesthetic standards.

## Design Standards & Hotkey Map
1. **Global Function Key Shortcuts:**
   - `F1`: Focus Global Product / Barcode Search
   - `F2`: Toggle Bilingual View (English / தமிழ்)
   - `F4`: Open Payment Tender Modal
   - `F8`: Preview / Print 80mm Thermal Receipt
   - `F9`: Hold Active Bill to Buffer (`SCR-E5`)
   - `F10`: Recall Buffered Bill
   - `Escape`: Cancel Modal / Dismiss Slide-Over Drawer
2. **Fintech Design Tokens (Behance Reference):**
   - Canvas: Airy soft slate `#f8fafc`
   - Elevated Cards: Pure white `#ffffff` with `border: 1px solid rgb(226 232 240 / 80%)` and subtle drop-shadow `0 2px 10px -2px rgba(15, 23, 42, 0.04)`
   - Primary Brand: Royal Indigo `#4f46e5`
   - Numeric Typography: `font-tabular` / `font-mono` on all prices, quantities, taxes, and balances to ensure clean decimal column alignment.
3. **Status Color Semantics:**
   - Inward / Paid / In Stock: Emerald (`#10b981`)
   - Reorder Alert / Partial / Due Soon: Amber (`#f59e0b`)
   - Overdue / Payable Liability / Out of Stock: Rose (`#e11d48`)
   - Returns / Debit Notes: Purple (`#9333ea`)
